# Mobile Install

Indian Worker Mandi is now installable as a Progressive Web App.

## Download / Install Link

Open this page from the phone browser:

```text
/Mobile/Install
```

## Android

Use Chrome. If the install prompt is available, tap `Install App`.

## iOS

Use Safari. Tap Share, then `Add to Home Screen`.

## Notes

- Android APK/AAB packaging is a separate native wrapper or Play Store step.
- iOS does not install APK files. iOS users install the PWA from Safari or receive a native app through App Store/TestFlight.
- Core app workflows continue to use the live server, including login, bookings, payments, profiles, reviews, admin, client, and worker features.
